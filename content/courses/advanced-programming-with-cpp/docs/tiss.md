## Subject (as on TISS)

C++23 core language and standard library: basic concepts, type deduction, trivial types, pointers/references, value categories, conversions, lambdas, operator overloading, classes, smart pointers, iterators/ranges, constant expressions, templates/concepts, concurrency.

## Teaching methods

Lectures (hybrid video conference), discussion of case studies (in presence), programming assignments (homework).

## Lecturers
