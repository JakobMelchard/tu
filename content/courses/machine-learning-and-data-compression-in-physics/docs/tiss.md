## Subject (as on TISS)

Machine learning as a tool for data analysis and prognosis in science and engineering. Project work on the application of ML concepts in physics and engineering and on developing new tools, e.g. for data compression, optimisation problems, pattern recognition and the prediction of observables. "Ideally suited to deepen the knowledge acquired in the lecture 138.128 Machine Learning in Physics."
