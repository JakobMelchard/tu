## Teaching methods

Weekly lectures on theory, applied DL methods and practical tips for the student project. The project has three separately graded phases:

1. **Problem selection and dataset.** Find and investigate an interesting and challenging problem for which other approaches might not work as well as deep learning; free choice of area (computer vision, intelligent agents, machine translation, audio processing). Then assemble a suitable dataset — reuse an existing one or collect a new one.
2. **Model selection and implementation.** Select and apply a suitable model, and select appropriate tools to train and optimise it efficiently.
3. **Assessment and presentation.** Compare the solution against scientific work representing the state of the art. **"Finally, the project should be prepared in such a way that potential users could use it, e.g., via an API or a simple mobile application."**

A final report compiles the results; a short overview is presented in class at the end of the semester.

*(Transcription note: the TISS text enumerates three phases and then refers to "the results from those **four** phases". The number four is a leftover in the source; it is unchanged in 2025W and 2024W. All three official assignment sheets describe three assignments.)*
