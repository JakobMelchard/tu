# 194.189 PR Efficient Programs: notes

One note. The PR has no content of its own: it is the VU's method applied by
a group of 3–5 to a program of the group's choice, graded on a presentation
[P1] [S2]. The material to learn is in
[`../../efficient-programs/notes/`](../../efficient-programs/notes/README.md);
this folder holds the plan.

| # | note | one line |
|---|---|---|
| 01 | [Project playbook](01-project-playbook.md) | choosing the program, the team, milestones against the 2026W dates, what the presentation must contain, a results-log template, five questions |

**Sources.** `[P1]` is the PR's TISS page 2026W, transcribed in
[`../docs/tiss.md`](../docs/tiss.md). `[S<n>]` is the VU register
[`../../efficient-programs/refs/SOURCES.md`](../../efficient-programs/refs/SOURCES.md);
`[S2]` there is the course homepage, which the VU and the PR share.

**Course facts** [P1] [S2]: PR, 2.0 h, 3.0 ECTS = 75 h (60 h project, 7 h
presentation, 8 h holding and listening to presentations), blocked; grade
based on the presentation; registration and
deregistration 23.09–13.10.2026 23:59; presentations
Mon 16:00–18:00 in EI 2 on 14.12.2026, 11.01, 18.01 and 25.01.2027,
attendance required; accounts on `g0.complang.tuwien.ac.at` in Tuesday
batches. **Listed only for 066 937 Software Engineering; not in the CSE
curriculum**, so for 066 646 it can only be a free elective [P1]. The
lecturer recommends taking the PR in the same semester as the VU [S2].
